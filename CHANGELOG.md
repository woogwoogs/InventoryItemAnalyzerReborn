# Changelog

## LootLens v1.0.0

- Introduced a polished minimal interface.
- Attached compact and full analysis directly to native item tooltips.
- Added user-configurable gold-star loot ratings for every equipment slot.
- Added persistent ratings for qualifying items in the visible stash tab.
- Added equipped-item analysis and hover ratings.
- Added unique-item perfection scores based on variable rolls.
- Added real modifier tiers plus crafted and implicit modifier badges.
- Added stat-specific colors and clearer player-facing modifier wording.
- Improved weapon DPS, added-damage ranges, and defensive-stat calculations.
- Improved responsive layouts for armour, weapons, jewelry, and narrow tooltips.
- Removed the experimental chat-linked item analyzer for a cleaner stable release.
