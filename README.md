# InventoryItemAnalyzerReborn



Quickly identify valuable items without reading every modifier. An attempt to bring back something similar to the old plugin. 


Custom Star Rating System

Configure individual loot-rating rules for each equipment slot. Define which valuable stats count toward ⭐, ⭐⭐, and ⭐⭐⭐ ratings, with fully customizable thresholds for each stat.
